# Truf-Arena-Management
A web-based Turf Arena Management System that allows users to explore sports facilities, view turf details, make booking requests, and register for tournaments. Includes user authentication interfaces, booking management, admin dashboard, and a responsive user-friendly design. Developed using HTML, CSS, and JavaScript.

# 🏟️ Turf Arena – Sports Turf Booking Management System

## 📌 Project Overview

Turf Arena is a modern, web-based sports turf booking management system designed to make discovering and booking sports facilities simple and convenient.

Users can explore different sports venues, view turf details, submit booking requests, access their dashboard, and register for tournaments through a premium and user-friendly interface.

## 🎯 Objectives

- Provide an easy-to-use online turf booking platform.
- Display available sports facilities and venue details.
- Simplify the booking request process.
- Provide tournament information and team registration.
- Offer user and admin dashboard interfaces.

## ✨ Features

- Premium and responsive user interface.
- Home page with featured sports venues.
- Turf listing and details pages.
- Booking request form.
- Checkout and demo payment interface.
- Booking confirmation page.
- User login and registration interface.
- Player dashboard.
- Admin dashboard.
- Tournament listing and team registration.
- Contact and service information pages.

## 🛠️ Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling and responsive design.
- JavaScript – Frontend functionality.
- LocalStorage – Demo data storage.

## 🚀 How to Run

1. Download or clone this repository.
2. Extract the project folder.
3. Open the project in Visual Studio Code.
4. Run `index.html` using Live Server.
5. Explore the Turf Arena website in your browser.
