TURF ARENA – PREMIUM SPORTS TURF BOOKING WEBSITE

This frontend demo is styled with a premium dark-navy and gold visual direction inspired by the supplied Grand Azure Resort reference project, adapted for sports turf discovery and booking.

PAGES
- index.html – Homepage and featured venues
- turfs.html – Browse turf venues
- turf-details.html – Venue details
- booking.html – Booking request form
- checkout.html – Booking summary
- payment.html – Demo payment interface
- confirmation.html – Booking confirmation
- auth.html – Sign-in / registration interface
- dashboard.html – Player dashboard
- admin.html – Admin dashboard demo
- tournaments.html – Tournament listings
- services.html, about.html, contact.html – Supporting pages

ASSETS
- images/football.jpg
- images/cricket.jpg
- images/badminton.jpg
- images/night-turf.jpg

RUN
Open index.html in a browser, or use a local Live Server.

IMPORTANT DEMO LIMITATIONS
This is a static HTML/CSS/JavaScript frontend demonstration. Booking and account interactions are demo-only and may use browser localStorage. There is no production backend, database, real-time slot inventory, secure authentication, or real payment gateway. Do not enter real payment details.
